# Image prompt construction

## Review a supplied prompt

- Honor requests to use the prompt verbatim. Otherwise, check the subject, protected facts, scene, composition, lighting, style, and constraints that matter for this image. Details the user leaves to the model can stay open.
- If the prompt is clear, consistent, and sufficient for the requested result, return or submit it verbatim. Apply the same check to a general request to optimize the prompt.
- Resolve material gaps, ambiguity, or conflicts from the brief and references first. Ask only when the user's intent is still unclear and would materially affect the result.
- Edit only the words needed to resolve the issue, apply the requested change, or satisfy required reference syntax. When one line is enough, append it and preserve the original wording. When the user clarifies a phrase, change only that phrase.

## Recommended order

For a new prompt or a targeted addition, use the details below that affect the result. Prioritize protected facts, exact copy, and explicit constraints.

1. Destination and medium: product photograph, editorial portrait, poster, thumbnail, or marketing still.
2. Subject and protected facts: identity, product structure, exact colors, logo, or copy.
3. Action or visual concept.
4. Environment, time, weather, and mood.
5. Composition: aspect ratio, framing, camera height, focal hierarchy, negative space, and safe areas.
6. Lighting and color.
7. Materials, textures, surface detail, and degree of realism.
8. Constraints: subject count, details to preserve, and any text or elements the user wants excluded.

Translate abstract requests such as "premium," "cinematic," or "high quality" into visible lighting, depth of field, material, color, and composition decisions instead of stacking adjectives.

## Multiple references

Assign roles before writing the creative prompt. Identity, product structure, composition, style, and official logo references are not interchangeable. Transfer only the visual traits the user selected from a style reference; do not transfer identity or composition unintentionally.

## Exact text

- Preserve user-provided copy verbatim.
- When the user chooses to add text in post-production, leave space for the planned copy in a text-free base image.
- When the user requests generated text, use the exact copy and follow any specified placement, hierarchy, language, or styling. For a title-only edit, add just the requested title and preserve existing labels. Restrict other text only when the user requests it. Check spelling and layout if you can inspect the result.

## Controlled variants

Apply all requested changes and preserve the other details. For comparisons designed to isolate one feature, vary only that feature: concept, framing, composition, mood, color, expression, or action. Do not replace a clear creative request with a batch of near-duplicates.

Avoid conflicting camera instructions, long repetitive negative lists, and unverified product or brand claims.
